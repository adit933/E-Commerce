# Full Stack E-Commerce Website

A full-stack e-commerce web application developed using React.js, Node.js, Express.js, and MongoDB. The application provides a complete shopping experience with user authentication, product management, cart functionality, checkout, and an administrative dashboard.

## Features

### User Features
- User Registration and Login
- Secure Authentication using JWT
- User Profile Management
- Address Management
- Browse Products
- Product Search and Filtering
- Product Details
- Shopping Cart Management
- Quantity Update and Product Removal
- Checkout and Order Placement

### Admin Features
- Admin Dashboard
- Product Creation and Management
- Update and Delete Products
- Featured Product Management
- Product Search and Filtering
- User and Order Management

## Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Backend Setup

```bash
cd backend
npm install
```

Configure the required environment variables in your backend `.env` file.

### 3. Frontend Setup

```bash
cd frontend
npm install
```

Configure the frontend environment variables if required.

### 4. Run the Application

Start the backend and frontend development servers in separate terminals using the scripts defined in their respective `package.json` files.

## Environment Variables

Configure the required environment variables for:
- MongoDB connection
- JWT authentication
- Cloudinary configuration
- Frontend API base URL

Never commit actual credentials or secret keys to GitHub.
